## Terminologies

- `vulnerability`
  - a security weakness in a system
  - Bad Software Code
- `exploit`
  - the method used to break in through that weakness
  - Program that exploits code to get inside
- `payload`
  - the harmful code that executes once the attacker is inside.
  - Stealing Data, Ransomwares etc.
